# The SSaDa (더 싸다) 🏷️

> **구글의 심플함과 애플의 정제된 감성을 결합한 글로벌 최저가 동시 검색 엔진**  
> 아마존(US), 아마존 재팬(JP), 네이버(KR)를 한 번에 검색하고, 최저가 분석과 절약 금액을 실시간으로 확인하세요.

---

## ✨ 핵심 기능

1. **3대 플랫폼 동시 새 탭 검색**
   - **아마존 (Amazon US)**: 글로벌 직배송 · $200 목록통관 면세
   - **아마존 재팬 (Amazon JP)**: 엔저 특가 직구 · $150 관세 면세
   - **네이버 쇼핑 (Naver)**: 국내 최저가 비교 · 빠른 배송 & NPay 적립
   - 체크된 사이트의 검색 결과가 클릭 한 번에 각각 새 탭으로 동시에 열립니다.

2. **실시간 최저가 판별 & 절약 금액 계산**
   - 비교 대상 중 가장 저렴한 1위 사이트를 자동 추천
   - 최고가 대비 **The SSaDa를 통해 얼마를 아꼈는지(₩)**와 절약 비율(%) 실시간 분석
   - 탭에서 확인한 실제 가격을 직접 클릭하여 수정(Fine-Tuning) 가능

3. **실시간 환율 & 관부가세 면세 한도 안내**
   - $1 = ₩1,385 / ¥100 = ₩925 기준 실시간 원화 환산
   - 미국 직구($200 이하) 및 일본 직구($150 이하) 면세 여부 자동 판정

4. **애플 디자인 철학 & 미니멀리즘**
   - Pretendard & SF Pro 타이포그래피
   - 은은한 Frosted Glass (반투명 블러) 효과
   - 다크 모드 / 라이트 모드 완벽 지원
   - 편리한 키보드 단축키 (`/` 검색창 포커스, `1` `2` `3` 플랫폼 토글, `Enter` 검색)

5. **데스크톱 단독 실행 지원 (`the_ssada_desktop.html`)**
   - 서버나 빌드 과정 없이 더블클릭만으로 실행되는 100% 독립형 HTML 파일 제공

---

## 🛠️ 기술 스택

- **Framework**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide Icons, Glassmorphism
- **Animations**: Motion

---

## 🚀 로컬 실행 방법

```bash
# 1. 저장소 복제
git clone https://github.com/gogo1111kjm/The-SSaDa.git

# 2. 의존성 설치
npm install

# 3. 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속하여 사용할 수 있습니다.

또는 저장소 내 `the_ssada_desktop.html`을 브라우저로 직접 열어서 바로 사용할 수도 있습니다.
